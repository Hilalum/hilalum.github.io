## Introduction

Thank you for using **RoomBoard** ("the App"). This application is a client for Apple TV, Android TV, and Android phones, allowing users to conveniently access and control their Home Assistant services.

We value your privacy. This policy explains how we handle your information.

## Data Collection and Use

1.  **Data Ownership**: Your home data belongs entirely to you. The App serves solely as a tool for display and control and does not perform any data mining.
2.  **Direct Connection**: The App communicates directly with the Home Assistant instance that you host or configure yourself. All requests for device status and control commands occur directly between your device and your Home Assistant server; they never pass through a server run by the developer.
3.  **Local Storage**: Your configuration information (such as server address and access tokens) is stored only in the secure storage area of your local device (Apple Keychain on Apple TV, encrypted storage on Android), solely for the purpose of connecting the App to your Home Assistant instance.
4.  **Anonymous usage statistics (Apple TV app)**: To understand whether setup and everyday use work as intended, the Apple TV app sends privacy-minimized product interaction events to a developer-operated analytics service (Hilalum Analytics). An event contains the event name, time, app version, build number, platform, locale, and a small set of fixed values such as the setup step, the device category used (for example "light" or "climate"), the result ("success" or "failed"), and a generic error category (for example "unreachable" or "auth_failed").
    *   We do **not** send device or entity names or IDs, room names, your Home Assistant address, access tokens, usernames, passwords, IP addresses you entered, free-form text, advertising identifiers, or persistent device identifiers.
    *   These statistics are not linked to your identity and are not used to track you across apps or websites.
    *   The Android versions of the App do not send these statistics.

## Third-Party Services

*   **Home Assistant**: As a client, the App relies on your personal Home Assistant service via its official API. For privacy practices regarding Home Assistant itself, please refer to its official documentation; this typically depends on your own server configuration.
*   **Hilalum Analytics**: Receives only the anonymous usage statistics described above.

## Changes to This Privacy Policy

We will update this privacy policy if the App's data practices change. Any changes will be posted on this page with an updated "Last Updated" date.
