先说一个冷知识。

《西游记》里，唐僧有个小名，叫**江流儿**——因为他刚出生就被放进江里漂走，被金山寺的长老捞起来抚养。

而在地球另一端的《圣经·出埃及记》里，摩西这个名字（希伯来语 Moshe，מֹשֶׁה）的字面意思，按经文自己的解释，就是**「从水里拉出来的」**。法老的女儿在尼罗河边捡到这个漂来的婴儿，给他起了这个名字。

也就是说：**摩西，其实也叫江流儿。**

一个是佛教取经故事的主角，一个是犹太教、基督教、伊斯兰教共同尊崇的先知。两个人相隔上万公里，故事成型的时间相差上千年，彼此几乎不可能互相抄袭。可你把他们的人生履历并排放在一起看，会惊出一身冷汗——简直像同一个编剧写的两版剧本。

不信？我们一条一条对。

# 第一幕：出生，就撞上杀身之祸

**唐僧**的故事是这样的（《西游记》附录「陈光蕊赴任逢灾」）：他父亲陈光蕊高中状元，携新婚妻子殷温娇赴任江州，途中被船夫刘洪谋害，尸沉江底。刘洪霸占了殷温娇，冒名顶替去做官。此时殷温娇已有身孕——这个孩子一出生，就是仇人眼中的祸根，随时可能被害。

**摩西**出生时,埃及法老正下达一道命令：所有希伯来人新生的男婴，一律扔进尼罗河淹死。因为法老害怕希伯来人丁兴旺，威胁埃及。摩西一落地，头上就悬着一道死刑令。

你看，两个人的起点一模一样：**还没学会哭出声，世界就已经容不下他们了。**一个面对的是私仇（杀父仇人），一个面对的是公权（法老的屠杀令），但处境相同——活下去本身就是奇迹。

# 第二幕：一条河，一个婴儿

接下来是整个故事里最动人、也最诡异地雷同的一段。

殷温娇为了保住孩子，咬破手指写下血书，把婴儿绑在一块木板上，放进长江，任其漂流。她赌的是一线生机：留在身边必死，放进江里，或许天可怜见。

摩西的母亲约基别把儿子藏了三个月，实在藏不住了，就取来一个蒲草箱，**抹上石漆和石油防水**，把婴儿放进去，搁在尼罗河边的芦苇丛中。他的姐姐米利暗远远站着，看这箱子漂向何方。

两位母亲做了同一个决定：**与其让孩子死在确定的命运里，不如把他交给一条河。**

河在这里不只是河。在几乎所有古老文明的想象里，水都同时意味着两件事——死亡与新生。基督教的洗礼是「没入水中、重获新生」；佛教讲「苦海无边」，讲「慈航普度」；连我们的成语都说「past 已成东流水」。婴儿入水，等于象征性地「死」了一次，然后以新的身份被世界重新接纳。

这个母题（motif）在神话学里有个专门的名字，叫**弃婴漂流母题**。它出现的频率高得吓人：阿卡德帝国的萨尔贡大帝，传说也是被母亲放进涂了沥青的篮子、顺幼发拉底河漂走的；罗马建城者罗慕路斯兄弟，被扔进台伯河；印度史诗《摩诃婆罗多》里的迦尔纳，被母亲放进箱子顺河漂走。全世界的伟大人物，好像都得先漂一段河。

# 第三幕：在「别人家」长大

被河流带走的孩子，都被意想不到的人接住了。

江流儿漂到金山寺，被法明长老收养，在寺院里长大，剃度出家，法名玄奘。他是在**佛门**里长大的——这恰好为他日后的取经使命埋下伏笔。

摩西的箱子被谁捡到了？**法老的女儿**。那个下令屠杀希伯来男婴的法老，他的女儿把摩西抱回了王宫，当埃及王子养大。摩西是在**敌人的宫殿**里长大的——而这恰好让他学会了埃及的一切学问，为日后与法老对峙做好了准备。

注意这个精妙的共同点：两个人都不是在亲生父母身边长大的，而且养育他们的环境，恰恰就是他们未来使命的「训练营」。命运绕了一个大弯，但每一步都没有浪费。

# 第四幕：神的召唤

长大成人之后，两个人都过了一段安稳日子——然后，神来敲门了。

玄奘在长安主持水陆大会，讲经说法，风光无限。这时**观音菩萨**现身点化：你讲的是小乘佛法，度不得亡者超生；大西天天竺国大雷音寺有大乘佛法三藏，能超亡者升天、度难人脱苦。玄奘当场立愿：不取真经，永堕沉沦。唐太宗与他结拜，赐号「三藏」，送他西行。

摩西呢？他因故逃出埃及，在米甸旷野当了几十年牧羊人，眼看要平淡终老。某一天，他在何烈山看见一丛**荆棘在燃烧，却烧不毁**。他走近去看，火焰中传来耶和华的声音：我听见了我的百姓在埃及的哀声，我要差遣你去见法老，把以色列人从埃及领出来。

两场召唤，结构完全一致：

- 都发生在主角「本来可以就这样过一辈子」的时刻；
- 都由神亲自现身（观音菩萨 / 燃烧的荆棘）；
- 使命都不是为自己，而是**为众生**——一个为东土大唐的芸芸众生取回度人的真经，一个为受苦的以色列民争取自由；
- 而且两人一开始都不算「够格」：玄奘是肉眼凡胎的和尚，摩西自称「拙口笨舌」，还推辞了好几次。

宗教故事里的英雄，从来不是自告奋勇的。**是使命找上他们，而不是他们找上使命。**

# 第五幕：带领众人上路，然后——受难开始

接下来就是两个故事的主体部分了，也是我们最熟悉的部分。

唐僧带着孙悟空、猪八戒、沙僧、白龙马，一行人（外加一匹马）西行十万八千里，**九九八十一难**，一难都不能少——观音菩萨最后盘点难簿，发现只有八十难，硬是补了最后一难，才凑齐八十一之数。

摩西带着以色列全族出埃及，法老追兵在后，红海在前——海水分开，走干地而过；然后是**旷野漂流四十年**：没水喝、没饭吃、天降吗哪、百姓抱怨、造金牛犊、瘟疫、战争……一代人几乎全部倒在旷野里，才轮到下一代进入应许之地。

这里有个特别值得玩味的细节：**磨难在两个故事里都不是意外，而是设计。**

八十一难是佛祖与观音「安排」好的功课，少一难都不行；旷野四十年是耶和华的旨意，为的是熬炼这个民族，把「埃及的奴性」从他们骨子里洗掉。换句话说，两个宗教在这里说了同一句话：

> **苦难不是修行路上的障碍，苦难本身就是修行。**

取经的意义不在真经，在取的过程；出埃及的意义不在迦南，在旷野的四十年。这大概是东西方宗教最深的一次握手。

顺便说一个残酷的对称：摩西最终**没能进入应许之地**，他只在尼波山上远远望了一眼迦南，就死在了约旦河东；而唐僧取到的第一批经书是**无字经**，还得回头再求一次，取回真经后师徒还要经历最后一难、落水晒经。两个故事都拒绝给你一个干净利落的圆满结局——因为它们想说的本来就不是结局。

# 所以，东西方宗教到底在哪里相通？

看完这五幕，该回答标题里的问题了。为什么两个不可能互相认识的文明，讲出了几乎同一个故事？

**第一种解释是神话学的。**美国神话学家约瑟夫·坎贝尔在《千面英雄》里提出过著名的「英雄之旅」（Hero's Journey）理论：全世界的英雄神话，无论出自哪个文明，都遵循同一个深层结构——**启程（受到召唤）→ 启蒙（试炼与磨难）→ 归来（带着恩赐回归，福泽众人）**。唐僧和摩西，是这个模板下最标准的两份答卷。坎贝尔的解释是：这不是巧合，而是因为所有人类共享同一种心灵结构，我们对「一个人如何成为更高的存在」有着共同的想象。

**第二种解释更朴素，也更动人：因为人类面对的根本处境是一样的。**无论长安还是埃及，人都会问同样的问题——苦难有没有意义？我为什么而活？谁来带我们走出困境？宗教就是不同文明对这些问题给出的答案。答案的「包装」千差万别（佛陀 / 耶和华，真经 / 律法，灵山 / 迦南），但答案的「结构」惊人一致：

| | 唐僧（佛教） | 摩西（犹太-基督教） |
|---|---|---|
| 险境中出生 | 父亲被害，遗腹子 | 法老屠杀男婴 |
| 放入河中 | 长江，木板 | 尼罗河，蒲草箱 |
| 被收养 | 金山寺法明长老 | 法老之女 |
| 神的召唤 | 观音现身点化 | 燃烧的荆棘 |
| 带领众人 | 师徒四人西行 | 以色列全族出埃及 |
| 设计好的磨难 | 九九八十一难 | 旷野四十年 |
| 目的地 | 灵山·真经 | 迦南·应许之地 |
| 不圆满的圆满 | 先得无字经 | 摩西本人未入迦南 |

**领路人必须先受难**——这是两边共同的信念。真正的领袖不是最强的人（唐僧论武力是全队最弱的，摩西自己都说不利索话），而是那个被拣选、肯受苦、不回头的人。神通广大的是孙悟空，分开红海的是耶和华，但故事的主角永远是那个一步一步走路的凡人。

**水是重生，旷野是课堂，远方有应许**——把这三句话说给一个和尚听，他会点头；说给一个拉比或牧师听，他也会点头。

# 尾声

最后做一点诚实的补充：唐僧「江流儿」的身世出自《西游记》的文学创作，历史上真实的玄奘出身士族、少年出家，并没有漂过江。但这反而让对比更有意思了——**吴承恩（或者更早的说书人）在给玄奘编造身世时，不约而同地写出了一个「东方摩西」**。他们没读过《出埃及记》，却写出了同样的开头。

这说明弃婴、河流、召唤、旷野这套叙事，不属于某一个宗教，而属于全人类共同的想象。或者用更浪漫的说法：

**东方和西方各自坐在大河的两岸，讲了一夜故事。天亮时发现，讲的是同一个。**
